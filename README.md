# Paper Please Audio Replacer

[中文](#中文) | [English](#English)

## 中文

替换深空当铺的**呼叫下一位顾客**、**呼叫治安部请求协助**和顾客对话的音效为 Paper Please 的适配音效

### 安装

去右侧的 Release 界面下载 zip 后把整个 `PaperPleaseAudioReplacer` 文件夹解压到游戏的 `Mods` 目录：

```
Probably Stolen/Mods/PaperPleaseAudioReplacer/
├─ Sounds
├─ PaperPleaseAudioReplacer.dll
└─ manifest.xml
```

就应该只有 **2 个文件** 和 **1 个文件夹**

然后在游戏的 Mod 面板里启用它，重启游戏。
